# 📝 Lista de Tarefas

Projeto de uma lista de tarefas desenvolvido com **HTML, CSS e JavaScript**.

O objetivo foi praticar conceitos de JavaScript como manipulação do DOM, eventos, arrays, funções e armazenamento de dados utilizando **LocalStorage**.

## 🚀 Funcionalidades

* Adicionar tarefas;
* Remover tarefas;
* Visualizar lista de tarefas;
* Salvar tarefas no navegador;
* Interface responsiva para diferentes telas.

## 💻 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## 📚 Sobre o projeto

Este projeto foi desenvolvido para estudos e evolução no desenvolvimento Front-End.
